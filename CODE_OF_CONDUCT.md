# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion on the topic.
Harassment, insults, and personal attacks are not accepted.

Report unacceptable behavior privately to the maintainers through the
[Security advisory form](https://github.com/sipherxyz/ai-seo/security/advisories/new)
or by contacting a code owner listed in `.github/CODEOWNERS`.
Maintainers may remove comments, close issues, or block users who break these rules.
